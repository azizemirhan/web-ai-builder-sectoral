# Purpose

Feature one project inside a larger page: a strong image, a short story, and a route into the full
project.

# Visitor Intent

The visitor has met the practice and wants one piece of work in a little more depth before
deciding whether to look further.

# Content Responsibility

One project at section scale: lead image, short narrative, concise metadata, a few selected
details, and the onward link.

# In Scope

- A strong lead image, and a small number of supporting images
- A short project story
- Concise factual metadata
- A few selected project details
- An onward link to the full project page

# Out Of Scope

- A global site header, primary navigation or footer
- **The complete project detail page**, which is S24 — this is a section, not the whole page
- A technical case-study document, dossier or credits grid as the section's framing
- The full project gallery, which belongs to S14
- Fabricated clients, budgets, areas, dates or outcomes
