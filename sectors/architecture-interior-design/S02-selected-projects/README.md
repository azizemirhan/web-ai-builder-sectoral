# Section Name

Selected Projects

# Sector

Architecture & Interior Design

# Prefix

ARC

# Purpose

A curated index of the practice's projects on the homepage or a landing page: enough of each
project to recognise it, and a route into the project detail page.

# Visitor Intent

The visitor wants to see the work. They are scanning projects for something that resembles what
they need.

# Content Responsibility

A selected set of projects: project image, project name, brief factual context, and the link
onward.

# In Scope

- Project media, as the primary content of the section
- Project name and short factual context such as typology or location
- An onward link per project, and optionally one route to the full index

# Out Of Scope

- A global site header, primary navigation or footer
- One project in depth, which belongs to S13 and to S24
- The full uncurated archive
- Fabricated clients, dates, awards or completed-project claims
