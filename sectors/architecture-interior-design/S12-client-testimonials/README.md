# Section ID

ARC-S12

# Section Name

Client Testimonials

# Sector

Architecture & Interior Design

# Prefix

ARC

# Purpose

Present what clients have said about working with the practice.

# Visitor Intent

The visitor wants reassurance from someone other than the practice itself before making contact.

# Content Responsibility

Quotations and their attribution, with the project context that makes them meaningful.

# In Scope

- The quotation, given typographic weight
- Project imagery associated with the quotation
- An optional portrait where appropriate and real
- Project or role context for the attribution
- A curated quote composition or carousel

# Out Of Scope

- A global site header, primary navigation or footer
- **Fabricated testimonials, clients, ratings or attributions** — nothing here may be invented
- Interview-transcript or prequalification-annex density
- Case study narrative, which belongs to S13 and S24

These are authoring and research directions, not production enums, and the study IDs do not change
with them. The five studies must differ structurally. They must not become five colour schemes,
five font themes, five cosmetic variants, or five copies of one grid with the content swapped.

In this section:

- **003** holds several testimonials through visual grouping and paced modules rather than through
  longer quotations.
- **005** is an art-directed quotation composition — scale, crop, pairing with project imagery.
  Not a transcript or an annex.

**Recorded correction.** `ARC-S12-005` reproduces a prequalification annex and is a later visual
rework. Text density is naturally high in this section, which makes editing the quotations part of
the design work.

# Architecture Direction

Sector direction: `../ARCHITECTURE-DESIGN-DIRECTION.md`.

A testimonial reads as editorial when the quotation is short, the typography carries it, and a
project image sits beside it. Attribution discipline is a design constraint here, not a footnote.

# Section Shell

Section only. No global header, navigation or footer.

# Media Relationship

Expected. Project imagery, and an optional portrait only where a real person has consented.

# Interaction Notes

Optional. A carousel is plausible and must be keyboard operable, must not autoplay without a
control, and must leave every quotation reachable without script.

# Responsive Considerations

Quotation and attribution must never separate across a reflow, and large quotation typography must
remain unclipped at 320px.

# Authoring Questions

- **Primary visual element:** the quotation as typography, paired with project imagery.
- **Immediate understanding:** that real clients value working with this practice.

Full authoring question list: `../ARCHITECTURE-DESIGN-DIRECTION.md`.
