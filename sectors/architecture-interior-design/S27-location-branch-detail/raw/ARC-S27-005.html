The approach

Each move is lettered, and the letter keys to the plan area beside it. The letters are text, so the sequence reads on its own when the plan is empty — which is the point of describing a place this way rather than handing over a map.

  1. A

    From the street

    Which side of the street the entrance is on, and what is next to it. Supplied by the studio.

  2. B

    The threshold

    What the door looks like, whether it is set back, and whether it is shared with other occupiers.

  3. C

    Getting up

    Stair or lift, and which one to take. Step-free access is a reserved field, filled by the studio.

  4. D

    Arriving

    Which floor, which door, and who to ask for on arrival.

  5. E

    Waiting

    Where to wait if you are early, inside rather than on the street.

Placeholder location page · structure demonstration only. The register is the keyed approach: street, threshold, stair, floor, each lettered against a reserved plan area, with the same lettering continued inside the studio. It is deliberately not the key plan of ARC-S22-005, which locates a page within a set and is navigation; this locates a visitor within a building and is arrival information. Every letter is real text, so the sequence survives with the plan area empty. Address, hours and contact routes are placeholder tokens or reserved fields; no distance, duration or coordinate is stated; and neither reserved area loads a third-party map or makes any remote request. The return line overlaps ARC-S22.
