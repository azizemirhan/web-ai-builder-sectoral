# Section ID

ARC-S18

# Section Name

Studio Stats

# Sector

Architecture & Interior Design

# Prefix

ARC

# Purpose

Give a small number of figures that convey the scale and reach of the practice at a glance.

# Visitor Intent

The visitor wants a quick sense of size and experience without reading an account of the practice.

# Content Responsibility

A few figures, each with a very short label, composed for impact rather than for completeness.

# In Scope

- Large numbers with strong typographic treatment
- Very short labels
- Optional supporting imagery
- A clean visual rhythm across the set

# Out Of Scope

- A global site header, primary navigation or footer
- **Statistics presented as measured drawings, data indexes or spreadsheets**
- Long explanations attached to each figure
- **Fabricated figures.** Every number must be verifiable in production use; placeholder figures
  must be obviously placeholder

These are authoring and research directions, not production enums, and the study IDs do not change
with them. The five studies must differ structurally. They must not become five colour schemes,
five font themes, five cosmetic variants, or five copies of one grid with the content swapped.

In this section:

- **003** may hold more measures, but through grouped visual panels — not as a data index with
  operational context attached to every figure.
- **005** is an art-directed numeric composition: scale, spacing and typographic contrast. Not a
  measured drawing.

**Recorded corrections.** `ARC-S18-002`, `ARC-S18-003` and `ARC-S18-005` were reviewed as too
technical or too text-heavy and are later reworks. The section carries almost no media anywhere,
which is part of why it reads as a data table.

# Architecture Direction

Sector direction: `../ARCHITECTURE-DESIGN-DIRECTION.md`.

`ARC-S18-001` already demonstrates the large-figure treatment this section wants. Big numerals,
short labels, generous space, and imagery where it helps the figures feel like a practice rather
than a dataset.

# Section Shell

Section only. No global header, navigation or footer.

# Media Relationship

Optional but encouraged. Supporting imagery is the main lever against this section reading as a
spreadsheet.

# Interaction Notes

Normally none. Any count-up animation must respect reduced motion and must not be required to read
the figure.

# Responsive Considerations

Large figures must scale down without clipping, and a four-across set must reflow to a readable
stack rather than shrinking the numerals into their labels.

# Authoring Questions

- **Primary visual element:** the figures themselves, as typography.
- **Immediate understanding:** the scale and reach of the practice.
