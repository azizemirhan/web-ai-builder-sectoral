The process, stage by stage

Five stages · what each one produces

  1. 01

    Brief and site

    Survey, constraints and the written brief, recorded together before any option is drawn.

    Output
    Site notes, agreed brief
    Studio does
    Survey, constraint review
    You provide
    Requirements, existing documents
  2. 02

    Concept design

    Options tested in plan and section until one is worth developing, with the reasoning written down.

    Output
    Concept drawings, study model
    Studio does
    Option testing, massing
    You provide
    Feedback, chosen direction
  3. 03

    Developed design

    The chosen option resolved in detail, with structure, services and material coordinated onto one set.

    Output
    Developed drawing set
    Studio does
    Coordination, material selection
    You provide
    Sign-off on the set
  4. 04

    Technical design

    Construction information: junctions drawn, components scheduled, specification written to match.

    Output
    Construction set, specification
    Studio does
    Details, schedules, tender support
    You provide
    Procurement decisions
  5. 05

    Site and handover

    The studio stays on the project while it is built, answering queries and reviewing what is made.

    Output
    Handover set, as-built notes
    Studio does
    Site visits, query responses
    You provide
    Access, instructions to the builder
