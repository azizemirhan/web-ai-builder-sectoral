# Section ID

# Section Name

Capabilities

# Sector

Architecture & Interior Design

# Prefix

ARC

# Purpose

Explain what the practice is capable of taking on: the scale, disciplines and kinds of commission
it can handle.

# Visitor Intent

The visitor is checking fit — whether this practice can carry a project of their size and
complexity.

# Content Responsibility

Capability groups: what the practice can do, at what scale, and with which disciplines in house.

# In Scope

- Visual capability groups
- Concise capability modules
- Supporting media
- Icons, only where they add meaning rather than decoration
- Progressive disclosure and card or grid systems
- A route into the relevant services

# Out Of Scope

- A global site header, primary navigation or footer
- **A consultant matrix, appointment annex, scope schedule or technical capability grid** as the
  primary device
- The named service set, which belongs to S03
- Fabricated accreditations, certifications, insurances or team numbers

five font themes, five cosmetic variants, or five copies of one grid with the content swapped.

- **005** is an art-directed capability composition, not an appointment annex or consultant matrix.
