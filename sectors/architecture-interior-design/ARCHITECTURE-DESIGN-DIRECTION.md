# Architecture & Interior Design — Design Direction

Sector: Architecture & Interior Design · Prefix: `ARC`

This document is the sector application of the global authoring system. It does not replace
`../../standards/01-AUTHORING-STANDARD.md`, `../../standards/03-MEDIA-POLICY.md` or
`../../standards/05-RESPONSIVE-QA.md`; where the global standard and this document could be read
as competing, the global standard governs and this document supplies the Architecture reading of
it.

It applies to every `ARC` section, S01–S27, for future authoring and for later re-authoring of
existing studies.

## Position

**Architecture and interior design web design is primarily visual.**

The subject of this sector is space, light, material and proportion. A study earns its place by
composing those things, not by describing them. Copy supports the composition; it does not
substitute for it.

## Primary Visual Language

- architecture photography
- interior photography
- spatial photography
- material and texture imagery
- project details
- natural and artificial light
- proportion
- scale
- negative space
- editorial typography
- restrained composition
- large media fields
- carefully controlled asymmetry
- gallery-like pacing
- premium visual calm
- spatial rhythm

## Reference Register

An Architecture study should generally feel closer to:

- a premium architecture portfolio
- a contemporary design publication
- an art-directed studio website
- a curated project presentation

than to:

- an architectural drawing package
- tender documentation
- specification sheets
- technical schedules
- CV or bid documentation
- professional registers

## Anti-patterns

The following must **not** be used as a default Architecture styling device:

- `SHEET` labels
- drawing-number aesthetics
- `NTS` notation
- scale bars used decoratively
- `ISSUE` / `REVISION` blocks
- dossier layouts
- responsibility ledgers
- project registers
- specification tables
- programme sheets
- curriculum sheets
- technical matrices
- atlas diagrams
- technical drawing title blocks
- administrative document imitation

These are not absolutely forbidden. Under
*Technical and Professional Document Metaphors* in `../../standards/01-AUTHORING-STANDARD.md` one
may be used where the user or a supplied reference explicitly asks for that visual concept, or
where the role genuinely requires that artifact, and where the result still works as a modern web
interface. The justification is recorded in the section's batch document.

What they must not do is define the general Architecture visual identity. The failure this sector
has already produced is a catalog in which the most "distinctive" study in a section is reliably
the least visual one.

## Copy Direction

Visible Architecture website copy should generally be:

- concise
- confident
- editorial
- spatially aware
- easy to scan
- paired with visual content

Avoid:

- placeholder essays
- long explanatory prose
- specification-style writing
- verbose process documentation
- multiple paragraphs written only to prove content capacity

Architecture still requires genuinely detailed content on service detail, project detail, article
detail, profile detail and location detail pages. Those pages manage detail through visual
sections, media, headings, concise modules, progressive disclosure, accordions where appropriate
and clearly separated content blocks — not through uninterrupted copy.

## Media Direction

The media policy in `../../standards/03-MEDIA-POLICY.md` applies unchanged. Do not invent projects,
buildings, people, clients, awards or addresses. Reserved media areas are valid, intended output
and an empty one is not a defect.

Architecture studies should reserve visual space, at the right scale and position, for:

- project photography
- interior photography
- exterior photography
- detail photography
- material samples
- portraits
- drawings, only where genuinely relevant to the role
- video where appropriate

An Architecture study must not become text-only solely because real media cannot be fabricated.
Use quiet placeholders to represent future media.

## Section Shell — Architecture

An individual `ARC` study must not include a site-wide header, primary global navigation, a global
footer or an unrelated announcement bar, unless that component is itself the target role.

- **S01 Hero: hero only.** No logo, no navigation, no header shell.
- **Detail pages (S23–S27):** internal page content architecture is allowed; global website chrome
  is not.
- **Reference screenshots that contain a header must be read selectively.** Extract the requested
  role; do not reproduce the surrounding chrome because it happened to be in the frame.

## The Five Directions in Architecture

Study IDs do not change with these names. `ARC-S06-003` remains `ARC-S06-003`.

| Variant | Direction | Architecture reading |
| --- | --- | --- |
| 001 | Universal / Safe | The dependable, image-supported version of the role that any practice could ship. |
| 002 | Premium / Editorial | Publication pacing: large media, refined typography, whitespace, fewer and more deliberate blocks. |
| 003 | Structured / Visual Modular | More content capacity carried by **visual structure** — modules, panels, grouped media, disclosure — not by more prose or more fields. |
| 004 | Conversion-led | The enquiry or onward route shapes the composition, while the section keeps its content role. |
| 005 | Art-directed / Distinctive | The strongest spatial, photographic and typographic composition the role can carry while staying usable — not a professional document. |

The two directions this sector previously got wrong:

- **003 is not "more text and more fields."** If removing half the copy destroys the reason the
  study is different, it is not a successful 003. It must be information-*capable*, not
  text-*dependent*.
- **005 is not "make it look like architectural paperwork."** Every study 001–005 is already
  sector-aware. Architecture feels architectural through spatial imagery, material, proportion,
  light, whitespace and typographic control — not through title blocks, NTS marks, issue numbers
  or revision stamps.

## Section Authoring Questions

Before authoring or re-authoring any `ARC` study, answer:

1. What is the primary **visual** element of this role?
2. What must a visitor understand immediately?
3. Can media carry part of the meaning instead of additional prose?
4. Does 003 remain visually modular rather than text-dependent?
5. Does 005 look distinctive without becoming professional paperwork?
6. Would this composition still look like a modern website once real project media is inserted?

Each section README records its own answers to questions 1 and 2 under *Authoring Questions*.
