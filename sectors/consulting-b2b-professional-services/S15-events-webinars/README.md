# Section Role

What the firm does in person, and who else is in the room.

# The Trap

The default is a grid of cards with a stock photograph of a conference stage, a countdown, *limited
seats*, and a webinar that is a sales call with slides.

The tell is that a normal events grid gives a session for twelve and a conference for four hundred
the same 16:9 photograph, so **there is no way to tell them apart before attending.**

# The Governing Idea

> **What makes an hour worth it is who else is in the room.**

Not the speaker. So every entry names its format, who it is for, and what its cap is — and the
section says which of its own events is a broadcast rather than pretending all four are workshops.

# The Four Entries

| Format | Event | For | The cap |
| --- | --- | --- | --- |
| **Room of `twelve`** | The stage-03 session | Programme late, reporting says it is fine | Twelve. When it fills we run it again |
| **Broadcast** | The counterfactual hour | Anyone. No room, so no cap | We will not call it a workshop |
| **Someone else's stage** | A conference talk | Whoever bought a ticket | We do not control the room |
| **Closed** | A client briefing | One client's team | Not open and not on sale |

All five studies carry the same four.

# The Cap Is Real. The Urgency Is Not.

Twelve is a real limit with a reason — **thirteen makes it a lecture** — but a real cap is the
opposite of a countdown. No timer, no seats-remaining counter, no waiting list that is really a
mailing list. **When it fills we run it again.**

# The Closed Event, Listed Anyway

An events section is a claim about how much is happening, and that claim is only checkable if the
unavailable things are on it too. Leaving the closed briefing off would make the calendar look busier
with *open* events than it is.

# Why There Are No Speakers

Most events sections sell the speaker. This one sells the room. Portraits stay reserved sector-wide
in any case, but the omission is **a position rather than a constraint**: the speaker is the least
reliable predictor of whether an hour was worth it.

# The Media Question

The honest image is **the room, at the size it is actually run** — the rare case where the reserved
area *is* the argument. `002` shapes each area like its room, so a reader who never gets past the
images has still been told the truth. `003` carries none, because a photograph would soften the
figure rather than support it.

# What This Section Will Not Do

- **No countdown, no seats-remaining counter, no *limited seats*, no *register now*.** The cap is
  stated once with its reason, and what happens when it fills is stated too.
- **No waiting list that is really a mailing list.**
- **No attendee count as achievement.** *Join 500+ attendees* is a claim about the room being worse.
- **No speaker name, title or headshot.** The section sells the room.
- **No stock conference photograph.** The reserved area is the actual room, at its actual size.
- **No pretending a broadcast is a workshop.** The one that is a broadcast says so.
- **No global header or navigation.** The section-shell rule.
