Events

We cap the room at twelve. Thirteen makes it a lecture.

What makes an hour worth it is who else is in the room, so that is what each of these tells you.

Image area — the room, at the size we actually run it
  • Room of twelve

    The stage-03 session

    For people whose programme is late and whose reporting says it is fine.

    When it fills we run it again, within the quarter.

  • Broadcast

    The counterfactual hour

    For anyone. There is no room, so there is no cap.

    We will not call it a workshop. Recorded, and the recording goes up whether or not it went well.

  • Someone else’s stage

    A conference talk

    For whoever bought a ticket. We do not control the room.

    Useful for deciding whether to talk to us, not for getting work done.

  • Closed

    A client briefing

    For one client’s team. Not open and not on sale.

    Listed because leaving it off would make this calendar look busier than it is.

No countdown, no seats-remaining counter, no waiting list that is really a mailing list.

The cap exists so the session works, not to make you hurry.
