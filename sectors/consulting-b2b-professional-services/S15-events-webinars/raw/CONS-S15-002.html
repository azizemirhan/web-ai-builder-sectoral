Events

Each of these is shaped like its room.

What makes an hour worth it is who else is in it. A session for twelve should not look like a conference for four hundred, so here it does not.

  • The room · 3:2the room, at the size we run it

    Room of twelve

    The stage-three session

    For people whose programme is late and whose reporting says it is fine.

    When it fills we run it again, within the quarter.

  • The desk · 1:1no room; a desk and a microphone

    Broadcast

    The counterfactual hour

    For anyone. There is no room, so there is no cap.

    We will not call it a workshop. Recorded, and it goes up whether or not it went well.

  • The hall · 21:9the hall, from the back

    Someone else’s stage

    A conference talk

    For whoever bought a ticket. We do not control the room.

    Useful for deciding whether to talk to us, not for getting work done.

  • The door · 3:4a closed door

    Closed

    A client briefing

    For one client’s team. Not open and not on sale.

    Listed because leaving it off would make this calendar look busier than it is.

No countdown, and no seats-remaining counter.

The cap exists so the session works, not to make you hurry. When it fills, we run it again.
