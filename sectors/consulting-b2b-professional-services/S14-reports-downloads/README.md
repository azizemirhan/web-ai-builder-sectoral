# Section Role

The long-form work, and what it costs to get it.

# The Trap

The gated download is the most resented pattern in this sector: a form asking for name, email,
company, phone number, job title and company size in exchange for a PDF, with the word **free**
printed above it.

It is resented because it is untrue, not because it is expensive. The file costs an address — and
then whatever follows the address: a call, a list, a score in a system the reader cannot see.

# The Governing Idea

> **A gate is a price. Here is what each one costs.**

# The Four Reports And Their Prices

| Report | Price | What the price means |
| --- | --- | --- |
| The decision-rights audit | **No gate** | The file is a link. Nothing is collected |
| What cost programmes cost | **No gate** | The file is a link. Nothing is collected |
| The stage-03 exits | **One email address** | The file, and one message when the next one is published |
| The counterfactual problem | **A conversation** | We do not send this one. It is useless without the context |

All five studies carry the same four, so the batch varies by composition rather than by copy.

**Two of the four cost nothing**, which is what makes the price on the other two credible. A page
where everything is gated is a page where the word *price* means nothing.

The fourth is not a tactic. Some material is useless without the interpretation, and posting it as a
file would be a worse deception than gating it.

# The Two Commitments

**Six fields never asked for:**

> Phone number · Job title · Company size · Budget · Timeline · How you heard about us

**What happens to an address:**

> One list. Not sold, not enriched, not scored. Unsubscribing removes it rather than pausing it.

Naming the fields is more useful than a privacy assurance, because a reader can check six things
against the form in front of them and cannot check a promise.

# Sorted By What It Costs You

`003` orders the reports **cheapest to the reader first** — the one sort order no firm in this sector
uses, because it puts the ungated material at the front and the lead-generating material last. The
single reserved cover goes to the report at the front of that sort.

# The Media Question

The honest image is the one `S13` established: **the report's own cover.** Never a stock photograph.

`002` and `005` carry none, for the same stated reason: a cover is a picture of the product, and the
argument in those two studies is about the terms.

# What This Section Will Not Do

- **No use of the word *free*** except to say nothing here is described that way.
- **No *exclusive*, no *limited*, no download count, no page count.** Volume and scarcity signals.
- **No fabricated research figure.** No respondent counts, no *we surveyed N executives* — that
  asserts a survey system, which the theme contract omits sector-wide.
- **No form field beyond an address**, and the six that are never asked are printed.
- **No stock photograph.** The only reserved image is the report's own cover.
- **No global header or navigation.** The section-shell rule.
