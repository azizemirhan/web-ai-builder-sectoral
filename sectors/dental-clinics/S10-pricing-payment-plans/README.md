# The Trap

A tier table, or a list of *from* prices — a figure chosen because it is the least anybody has ever
paid, printed to win a comparison the visitor is making across four tabs. It describes almost nobody,
and every reader who has paid a dental bill knows it.

# The Governing Idea

> **A number you could read before anyone has looked is not a price.**

So there are no prices on any of these pages. What replaces them is more use: which treatments have
one fixed price, which cannot be quoted until somebody has looked and why, **when the number arrives**,
and the three things that can move it afterwards — the third of which closes the list.

# No Figures Anywhere In This Batch

The contract requires a stated price to be complete and the workspace does not invent one. **A
placeholder price is a fabricated quote** — the same class of thing as a placeholder credential or a
placeholder testimonial. `S01` set the convention for the sector: state the policy, not the number.

The scan for this section rejects any digit in visible text, any currency symbol or word, any
percentage or rate, any *from* price, and any named finance product.

# The Two Kinds Of Price

| One price, and it does not change | Cannot be quoted until somebody looks |
| --- | --- |
| The examination, the hygienist, an X-ray, the emergency appointment | A filling, a crown, an implant, aligners |
| Ask on the phone and you will be told | What they cost depends on how much tooth is left, how many surfaces, and whether the root is involved. Nobody can know that from a website |

# The Commitment

> **The number comes at the end of the first appointment, in writing, before anything starts.** Every
> option is on it, including doing nothing.

This is the answer a pricing section is actually being asked for, and it can be checked on the day. A
*from* figure cannot be checked at all.

# What Can Move It, In Advance

- **What is under an old filling.** We cannot see it until it is out. If there is more, we stop and
  re-quote before continuing.
- **A material you choose after seeing both.** Same work, different price, and you choose.
- **Nothing else.** If it is not on this list, it does not move the number.

# Paying

- You can pay in instalments, and the total is the same either way.
- If you stop part way, you pay for what was done and nothing more.
