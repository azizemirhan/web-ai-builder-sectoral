# The Trap

A grid of acronyms and beige boxes — *CBCT*, *CAD/CAM*, *intraoral scanner* — under a heading about
state-of-the-art technology. The patient cannot evaluate any of it, so it reads as a list of the
clinic's purchases rather than an account of their visit.

# The Governing Idea

> **Every machine here replaced something. That is the only reason it is listed.**

A machine is worth naming only if the difference is visible from the chair. So each item is written
as a swap: what it replaced, and what that removes for the patient. The putty tray is gone. The
referral is gone. The temporary crown is gone. The description of what we found is gone, because the
patient is looking at the same screen.

# The Field Nobody Prints

**What each machine does not do**, carried by all five studies at the same weight as what it does:

- The scanner cannot see under the gum.
- **The 3D X-ray uses more radiation than a flat one**, so one is taken only when a flat picture
  cannot answer the question.
- The milling unit does not suit every crown.
- A picture is not a diagnosis. Someone still has to read it.

The radiation line is the one every practice knows, every practice has a rule about, and no practice
publishes.

# The Closing Demotion

> **None of it makes a filling last longer than the hands that place it.**

Present in all five. A technology page that will not say this is selling the equipment rather than
the care.

# No Acronyms, No Brands

*The 3D X-ray*, *the milling unit*, *the scanner* and *the screen at the chair*. No study translates a
machine into a supplier's word or a model name.

# Media Relationship

This is the section the contract's media rule names explicitly: **the equipment the text names** is a
licensed subject, so equipment photography is honest here for the first time in the sector. Areas run
2 / 0 / 3 / 1 / 1.

`002` refuses media anyway and records why: **permitted is not the same as useful.** A photograph of a
machine is a beige box on a stand and cannot show what it replaced, how long the scan takes, or what
it fails to see.

`005` carries the batch's only whole-room area — the surgery with all four machines in it and none
singled out — because its argument is that no single machine is the point.
