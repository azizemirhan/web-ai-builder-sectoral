## Breaking A Flat Run

`S15` and `S16` carry **identical shape rows — `B C B B C` at every variant.** No contract rule forbids
it, but two sections running the same distribution back to back is the beginning of a habit, and the
third would have set it. `S17` is `B A B B C`.

The `A` is not there to break the pattern. It is there because **this is the one section in seventeen
that genuinely needs six photographs**, and the pattern being flat is what made the case easy to see.

## The Governing Idea

> **`Accessible` is a word. These are the parts that are and the parts that are not.**

The sector's version of this section is an embedded map, a pin, an address and *conveniently located.*
The map answers *where*, which nobody was in doubt about. **What a visitor needs to know is whether
they can get in** — and every clinic in this sector says *accessible* while none says which parts are
not.

## The Admissions

Shared across all five studies. Each failure carries what happens instead, and the workaround is never

| **The toilet is not accessible** | You are told when you book, not when you arrive |
| **There is no hearing loop** | Ask and we will write things down |
| **There is no parking**, and the street is permit-only | Nearest public car park a short walk; bus stops on the same street |

The parts that do work — street level, no step, the bell on the left, a hallway wide enough for a
wheelchair — appear in all five, and in none of them do they lead.

## What Was Already Reserved

`S11` and `S12` between them reserved **the telephone number and every clock time**; `S19` owns
contact. `S13` reserved named bodies and brands, which takes out the transport operator. So this
section carries **no address, no street name, no postcode, no telephone number, no opening hours and
no named operator** — and, as everywhere in this workspace, **no map embed**, which is a remote
dependency.

That constraint costs nothing. **An address and a street name answer *where*, and *where* was never the
question.** The questions a map cannot answer are the ones this section exists for.

## The Five Compositions

- **`001`** — the safe reading: two runs, `Getting in` and `Getting here`, with the door and the
  corridor paired between them. The three failures are set in the darker ink; the one fact that works
  is the quiet one.
- **`002`** — **`001` says in a sentence that the door gets missed; this does the thing the sentence
  describes.** Six frames down a single column in walking order: the corner, the shopfronts, the door,
  the hallway, the stairs, reception. Parking and transport sit below the sequence as text, because
  **putting them in a frame would make the walk dishonest.**
- **`003`** — the building written out as a specification. Three blocks: *ground floor, you can reach
  all of it*; *first floor, you cannot reach any of it*; and **`Not a floor problem`, which keeps the
  specification honest** — nobody is stopped by a staircase from installing a hearing loop, and filing
  it with the floors would let the building take blame it has not earned.
- **`004`** — the conversion-led reading. The device this replaces is a map, a pin and a *get
  directions* button, and **nobody was ever late because they did not know the address.** The band
  carries the three real causes. The third is the expensive one: a stairs-only appointment discovered
  on the day cannot be solved on the day.
- **`005`** — **marginalia.** Each failure is set at display size as the body text; each workaround
  hangs beside it, small, on a hairline. Every competitor has the two the other way round. Inverting
  the type sizes is the argument, and it is also honest about what a workaround is — *we will write
  things down* is not equal to a hearing loop, and setting it at the same size would pretend it was.

## Page Rhythm

Rule 1: `A` was available at every variant — `S15` and `S16` carry none. Taken once.

Rule 2 is satisfied at every assembled page from earlier batches; `005` adds a fifth-page `C` anyway,
and records its reason.

**Rule 4, the `C` record for `005`: you cannot photograph an absence.** Every line on that page is a
thing that is not there, and a photograph of the stairs is a photograph of stairs — the missing lift
does not appear in it. The only frames that would work are of the parts that *do* work, which would
put the weight on the half of the page that needs no help.

**Rule 3, for `003`'s two frames: the vantage is the argument.** Every other frame in the batch is shot
standing. These two are at seated height, because the two facts they carry are about a chair — a
hallway is wide enough or it is not, and a staircase from a seated eye-line is a different object from
one you are about to walk up. `S14` fixed this principle for rooms; this applies it to a route.

### Four instances of one CSS fault

The first render showed a rule ending in mid-air in `002`, `004` and `005`, and a fourth in the
`.close` of `001`, `002` and `004`.

**The cause was the same every time: a `border` on an element that also carries its own `max-width`.**
The rule stops where the *text measure* ends, not where the *section* ends, so a divider reads as a
stray underline. It is easy to miss in the source because both declarations are individually correct.

Two fixes, depending on what the element is:

- Where a wrapper exists, **the rule goes on the full-width element and the measure on the child** —
  `002`'s head, `005`'s `.works`, and `004`'s band rule, which moved off the headline and onto the
  `<ul>` beneath it.
- Where the bordered element *is* the text — the three `.close` paragraphs — **the measure comes from
  `padding-right`, not `max-width`.** Padding narrows the content box while the border still spans the
  full element, which is exactly the requirement. Reset to `0` at the `860px` breakpoint.

### A second fault, caught only by rendering

`003`'s three specification cards rendered **indented, with list markers beside them.** The inner lists
had `list-style: none`; the outer `<ul class="spec">` did not, and kept the browser's default
`padding-left`. **A list styled as a grid still needs its list reset** — the grid display suppresses
nothing.

Neither fault is detectable by any check in the batch script. Both required the render.

## What This Batch Fixes For The Rest Of The Sector

- **Never put a `border` and a `max-width` on the same element.** Four occurrences in one batch. The
  rule belongs to the section; the measure belongs to the text; they are different boxes.
- **`padding-right` is the measure control when the bordered element is the paragraph.**
- **A `<ul>` turned into a grid still needs `margin`, `padding` and `list-style` reset.**
- **Two sections with identical shape rows is a signal, not a violation.** Read the row before
  authoring the next one.
- **An accommodation is not equal to the thing it replaces, and the type should say so.** `005` sets
  the failure large and the workaround small on purpose.
- **The vantage is part of the media brief.** *The stairs* and *the stairs at seated height* are
  different photographs of the same object, and only one of them answers the question the text asks.
