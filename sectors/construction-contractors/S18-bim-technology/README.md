# Section Role

What a coordination model does for the person paying for the building, what it does not do, and how
to tell whether this job needs one.

# Two Anti-Patterns Govern This Section

From the sector direction:

> 4. **Stock plans, stock blueprints, stock CAD wireframe overlays.** A drawing you did not make is
>    a drawing of nothing.
> 5. **The clipboard-and-tablet montage.** Technology as a mood rather than as a capability.

Between them they remove every image this page is usually built from. They also remove the register:
**no page in this batch is drawn at an angle.** No wireframe, no isometric, no grid overlay, no
blueprint hatch, no rotated or skewed element anywhere — because all of them are the stock drawing
rebuilt in CSS.

# The Governing Constraint — It Moves Where You Find Out

    A model does not stop things going wrong. It moves the moment you find out — from
    the site to a room with the drawings still open.

That is the whole of the client-facing value, and it is measurable in the only currency this page
can print: **what fixing the same problem takes at each of four places.**

| Where it surfaces | What fixing it takes there |
| --- | --- |
| In the model, before anything is ordered | An email, and a revised object |
| At the drawing review, before fabrication | A revised drawing and a re-issue |
| **On site, in the work** | **A variation, and two trades standing while it is agreed** |
| **After handover, in the finished building** | **Opening something that was signed off** |

No figures. The escalation is stated as the work it takes, which is more use to a reader than a
percentage and is the only version of it this catalog could print anyway.

# The Six Things That Actually Get Coordinated

| Item | Found in the model | Found on site |
| --- | --- | --- |
| Services against structure | A penetration drawn, and a beam designed for it | A hole nobody will sign for |
| Ceiling void depth | A void that holds what is going in it | The first thing value-engineered, and the last thing anybody re-checks |
| Riser and plant space | Room to lift the thing out again, not just to fit it in | A pump that fits and cannot be replaced |
| **Builder's work openings** | Holes agreed before the pour | **Concrete does not have a revision** |
| **Setting out against the survey** | The model told where the building actually is | **On a refurbishment the building is never where the drawing says** |
| Who owns which object | A schedule saying who models what, to what level, by when | Two consultants each assuming the other did it |

The fifth is the caveat the rest of the page depends on:

    A model of an existing building is only as true as the survey underneath it.

Same shape as `S15`'s refusal to price around a missing survey. This sector keeps arriving at the
same input from different directions.

# The Honest Answer, And It Is Sometimes No

Carried by `004`:

> **Not every job needs one.** On a straightforward build with no services congestion, a model costs
> more than the clashes it would find, and we will say so rather than sell you one.

That is now this sector's standing conversion form rather than a novelty — `S09`, `S12`, `S13`,
`S14`, `S15`, `S16` and `S17` all convert by handing over the less flattering answer.

# What This Section Will Not Do

- **No software named, and no logos.** Which package we use is the least interesting fact on the
  page, and a row of logos is anti-pattern two in another costume.
- **No compliance level as a badge.** A level is a scope of work, not an achievement.
- **No fly-through.** A walkthrough sells a building; it does not coordinate one.
- **No maintained-twin claim we cannot keep.** An as-built model nobody updates is **a photograph of
  a building that has since changed** — so the page names who updates it and what happens when the
  answer is nobody.
- **No wireframe, no stock CAD overlay, no tablet-on-site photograph.** Anti-patterns four and five,
  named in the studies rather than merely avoided.

# Software Is Omitted, Not Reserved

The `S09` field-versus-figure test, applied again:

    Reserve the field when the empty field asserts nothing. Omit it when the empty field
    asserts a system.

A reserved slot labelled *Software* would assert that the package matters to the reader. It does not.
**Omitted in all five studies**, and two of them say why.
