# Section Role

The work itself. A set of completed and current projects, enough for a visitor to see the scale and
type of thing this firm actually builds.

It answers the sector's first question — **can you do this one?** — with evidence rather than
assertion, and it is the section a serious client scrolls first.

# The Governing Constraint — A Projects Section Cannot Name Its Projects

The sector direction rules out **client and project names** outright, and every figure a project
index normally carries with them: contract value, duration, floor area, number of units.

That removes the caption from every tile. What is left is the thing that was always doing the work:

    The picture is the point. A project index is looked at, not read.

So this batch is built the way the section is actually used — **image first, at scale** — with the
identifying text reserved and the honest, checkable attributes kept real:

| Element | Treatment |
| --- | --- |
| Project photograph | **Reserved area** — large, and the subject of every study |
| Project or client name | **Reserved field** |
| Location | **Reserved field** where a study shows one |
| Sector served | **Real** — healthcare, education, industrial, retail, civic, residential |
| Scope of work | **Real** — the `S02` vocabulary, and the same delivery marker |
| Status | **Real** — completed, or on site |
| Contract value | **Omitted** — the `S01` counter rule; a value per tile is an invented figure per tile |
| Duration, programme, handover date | **Omitted** — the `WELL-S08` rule |
| Floor area, unit count, storey count | **Omitted** — invented figures |
| Awards, ratings | **Forbidden** |

**A reserved name under a real photograph still works**, because the visitor is judging the building
in the picture, not the words under it. This is the same result `WELL-S18` reached for article
titles and `WELL-S24` for case studies, arriving in the sector where it costs the least: nobody
chooses a contractor by reading project names.

# What Is Real, And Worth More Than A Name

1. **The sector.** *Healthcare* tells a client more than a building's name ever will, because it
   tells them whether this firm has worked under their constraints.
2. **The scope.** Which of `S02`'s services this project actually was — and whether it was
   self-delivered or managed, carried through from `S02` unchanged.
3. **The status.** Completed or on site. Both are useful and neither is a claim.
4. **The constraint the job had.** *Occupied throughout*, *live traffic alongside*, *phased handover*
   — the thing that made it difficult. Authorable, uncopyable, and far more informative than a value.

# Media Relationship

**Central and dominant.** This is the most image-led section in the sector: every study is built
around large reserved project areas, and no study is legible as a text layout with the images
removed. Each area names what it expects and what it may not contain.

# Section Shell

at `<h2>` — the hero carries the `<h1>`.
