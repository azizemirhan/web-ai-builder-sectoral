## The Governing Constraint — A Projects Section Cannot Name Its Projects

The sector direction rules out client and project names outright, and every figure that normally
travels with them: contract value, duration, floor area, unit count. That removes the caption from
every tile.

What is left is the thing that was always doing the work:

    The picture is the point. A project index is looked at, not read.

So the batch is built the way the section is actually used — large images, identifying text
reserved, and the honest attributes kept real:

| Element | Treatment |
| --- | --- |
| Project photograph | **Reserved area**, large, in every study |
| Project or client name | **Reserved field** |
| Sector served | **Real** — healthcare, education, industrial, retail, civic, residential |
| Scope, and who delivered it | **Real** — carried through from `S02` unchanged |
| Status | **Real** — completed, or on site |
| Contract value, duration, area, unit count | **Omitted** — an invented figure once per tile |

**Twenty-seven reserved project areas across the batch**, and **twenty-three reserved name fields.**
No digit appears in visible copy anywhere in the batch.

**Why the reserved name costs nothing here.** Nobody chooses a contractor by reading project names,
so a labelled empty bar under a real photograph loses the section nothing — while `005` turns the
constraint into an argument outright: *"Clients decide what gets published about their buildings,
not us — and a contractor who prints a name without asking is telling you something about how they
will treat yours."* That is the same move `WELL` arrived at repeatedly, landing in the sector where
it is cheapest.

## What Replaces The Name — The Constraint

The most useful sentence available when the name and the value are both gone is **the thing that
made the job difficult**: *occupied throughout*, *live traffic alongside*, *a date nobody could
move*, *ground that argued*. It is authorable, uncopyable, and it is what a client is actually
scanning for — recognition of their own problem in somebody else's job.

Every study carries it; `002`, `004` and `005` lead with it.

## Study Records

### CON-S03-001 — Universal / Safe

- **Layout model:** A six-tile grid, each tile a large 4:3 reserved image with a status pill on it,
  a reserved name bar beneath, and one metadata line: sector, delivery chip, scope.
- **The dependable shape**, and the one that establishes the batch's reading order — picture, then
  sector, then what made it difficult. The name bar sits between them where a caption would, so its
  absence is legible as a reservation rather than as an omission.
- Closed by the line that explains the missing numbers: *"A number under a photograph is either
  commercially confidential or invented."*

### CON-S03-002 — Premium / Editorial

- **Layout model:** One project given the full width as a 21:9 lead plate with its detail set beside
  it in the margin, above a quiet three-up of smaller work.
- **The scale difference is the edit.** A grid treats every project as equally important, which is
  never true; a firm has one job it would show first if somebody walked into the office. The study
  is built the way that conversation goes — here is the one, and here are three others if you want
  them.
- The lead carries the constraint at reading scale rather than as a caption, which is what the
  editorial register buys.

### CON-S03-003 — Structured / Visual Modular

- **Layout model:** Indexed by sector — four rows, each with its sector label and a one-line
  description of that sector's difficulty held in the left margin, and two image tiles running
  across.
- **Indexed on the only thing a visitor can search on.** A client arrives knowing their sector, not
  a project name, so the sectors sit in the margin to be scanned in one pass while the tiles answer
  *how much of this have you done* without printing a count.
- **No filter control, deliberately.** A filter implies a database and a script; a section study has
  neither, and a control that appears to filter and does not is worse than none — the same reasoning
  that removed the slide counter from `CON-S01-005`. Static grouping does the same job.
- **Not a trade table**, which is this direction's trap in this sector: rows of images with a
  marginal label, not rows of cells.

### CON-S03-004 — Conversion-led

- **Layout model:** One very large reserved project area with a white panel over its lower half —
  sector, reserved name, the constraint, and one action — above four sector tiles as plain links.
- **The conversion is recognition.** A project index converts when a visitor sees their own
  constraints in somebody else's job, so the panel leads with *occupied throughout, deliveries
  through a live entrance* rather than with the building. The sector row underneath is the same
  offer for everybody else.
- **One project presented individually, four sectors routed** — which is why this study carries one
  reserved name rather than four, and why the checker's floor for this rule is one, not four.
- **What it refuses:** no *view all projects* count, no value, no logo wall, no testimonial. The
  action asks for the visitor's job rather than offering more browsing.

### CON-S03-005 — Art-directed / Distinctive

- **Layout model:** A staggered stack on charcoal — four very large plates alternating left and
  right, the sector set at display scale beside each, the name reserved beneath it.
- **The stagger forces a reading order.** A grid says *here is our portfolio*; a stagger says *look
  at this one, now this one*, giving each project the full width of attention for a moment. On a
  dark ground the plates read as lit objects, which is what a construction photograph is.
- **The sector is set as the headline** because, with names reserved and values omitted, it is the
  largest real word available.
- **Nothing is rotated.** The offset does the work, which keeps the study out of the car-advert
  register the sector direction warns about for this direction.
- **The closing line makes the constraint into the argument**, quoted above.

## Notes

- Third authored batch in the `CON` sector. `S01`, `S02` and `S03` are complete.
- **The reusable outcome is that the missing caption is not a loss.** In a portfolio section the
  identifying text is the least load-bearing element on the page — the picture and the constraint do
  the persuading. Any sector under confidentiality — construction, legal, defence, healthcare
  estates, anything with an NDA — can publish a real portfolio with every name reserved and lose
  nothing a client was using.
- The second outcome is `003`'s: **grouping is the static answer to a filter.** A section study
  cannot filter, and a control that pretends to is worse than none; indexing by the attribute the
  visitor would have filtered on gives the same result with no script.
- Two checker lessons, both familiar: the derived checker again picked up **literal backspace bytes**
  from shell escaping of `\b`, and its rule threshold was written for a shape (`>= 4` names) that
  `004` legitimately does not have. **A rule's floor must be set by what the section role requires,
  not by what the first four studies happened to do.**
- `S04 Sectors Served` is next in this sector.
