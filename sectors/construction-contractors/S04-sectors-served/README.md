# Section Role

Who the firm builds for — and, far more usefully, **what each of those clients makes difficult**.

# The Governing Constraint — A Sector Is Not A Category, It Is A Set Of Constraints

This section fails in a predictable way: it becomes a grid of sector names over stock photographs,
or a wall of client logos, and says nothing a competitor could not also say. Every contractor
"serves" healthcare, education, industrial and retail.

    Naming a sector is not a claim. Describing what that sector does to a programme is.

So the content of this section is **the constraint, not the category**:

| Sector | The constraint that defines it |
| --- | --- |
| Healthcare | The building stays open. Infection control, live entrances, agreed noisy hours |
| Education | A date nobody can move, and safeguarding around every gate |
| Industrial | Ground and loads decide the programme before anybody draws anything |
| Retail | A trading floor, weekend possessions, and a landlord as well as a client |
| Civic | The public alongside the works, and permissions in somebody else's gift |
| Residential | Neighbours who did not choose to be next to a site |

Each of those is **authorable** — it describes how work is done rather than what was achieved — and
**uncopyable in substance**, because a firm that has not worked in the sector cannot write the
specific version of it.

# The Boundary That Makes This Section Necessary

| Section | What it owns |
| --- | --- |
| `S02` Construction Services | **What you can hire us for** |
| `S03` Projects | **The work itself, seen** — photographs, grouped |
| `S04` Sectors Served | **Who we build for, as an argument** — the constraints and what we do about them |
| `S05` Capabilities | **What we hold in-house** |

    S03 shows the buildings. S04 explains why building for you is different.

**`S03-003` already indexes projects by sector.** If this section is another set of sector tiles
with photographs, it is `S03` again in a different order. The test for every study here: *if the
images were removed, is there still an argument on the page?* In `S03` the answer had to be no. **In
`S04` it must be yes** — which is why this section is carried by colour and type rather than by
photography, and why three of the five studies use no project media at all.

# What Is Real, And What May Not Be Invented

| Element | Treatment |
| --- | --- |
| Sector names | **Real** — generic vocabulary |
| The constraint each sector imposes | **Real** — a description of how the work runs |
| What the firm does differently | **Real** — operating practice |
| Which services usually apply | **Real** — the `S02` set, with its delivery markers |
| Client names, logos, authorities, frameworks | **Forbidden** — the logo-wall anti-pattern |
| Projects completed per sector | **Omitted** — an invented figure per sector |
| Share of turnover by sector | **Omitted** — a figure, and commercially private |
| Sector-specific certifications or schemes | **Forbidden** — the sector direction |

**Not present in any study:** a client name or logo, a framework or authority, a per-sector count or
percentage, a certification, an award, a rating, a price, a programme length, or an urgency device.

# The Second Piece Of Real Content — The Sector We Are Wrong For

On the pattern this workspace keeps arriving at. A sectors page that lists only sectors served is a
claim of universal competence, which nobody believes. Saying which sector the firm is **not** the
right answer for is the one line on the page a competitor will not copy.

`004` makes it the conversion device; `001` and `005` each carry a version.

# Media Relationship

**Secondary, by design** — the opposite of `S03`. Colour and type carry this section because the
content is an argument rather than evidence. `002` and `004` use one reserved area each; `001`,
`003` and `005` use none.
